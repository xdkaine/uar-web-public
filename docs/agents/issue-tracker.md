# Issue Tracker

Issues and PRDs are tracked in GitHub Issues for `xdkaine/uar-web` using the `gh` CLI or the connected GitHub app.

## Rules

- Read issue and pull-request state before proposing changes that depend on it.
- Search for an existing issue before suggesting a new one.
- Creating, editing, labeling, closing, or commenting on an issue or pull request is an external action and requires explicit user authorization for that exact action.
- Never infer permission to commit, push, open a pull request, or update an issue from permission to edit local files.
- Return links or identifiers after authorized writes and read back the resulting state.
