# Triage Labels

Use this vocabulary when triaging GitHub Issues:

| Label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer still needs to evaluate the issue. |
| `needs-info` | Work is waiting for information from the reporter or owner. |
| `ready-for-agent` | The issue is sufficiently specified for bounded agent work. |
| `ready-for-human` | The issue requires human judgment, access, or execution. |
| `wontfix` | The maintainers have decided not to action the issue. |

Do not create or rename labels without explicit authorization. If the repository's live labels differ, report the mismatch and ask before changing either system.
